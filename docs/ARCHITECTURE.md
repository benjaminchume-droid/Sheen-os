# Sheen OS Architecture

Sheen is a Linux-based, USB-first operating system. The shell is a client of system services. Media, TV, casting, vision, Android compatibility, storage, input, networking, updates and recovery are independent subsystems connected through stable APIs.

## Deployment
- USB live/persistent mode
- SSD installation
- old/new x86-64 PCs and laptops
- future ARM/dedicated Sheen hardware

## Compatibility
Android compatibility targets ordinary Android APKs first, with Android TV framework/input behavior as an additional surface. Compatibility does not imply every APK will work: proprietary Google services, DRM, native libraries and hardware requirements remain explicit capabilities.
